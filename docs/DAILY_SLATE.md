# Daily Slate Intelligence V2

## Purpose

Daily Slate Intelligence is the flagship homepage for TrueLine. It does not create new predictions or replace existing models. Its job is to orchestrate the existing intelligence products into one ranked slate experience.

The page answers:

- Which bets rank best across all available markets?
- Which strikeout, hits, home run, and moneyline opportunities deserve deeper research?
- Which weather, bullpen, and lineup conditions matter today?
- Where should the user click next for full analysis?

## Architecture

The orchestration layer lives in `src/features/daily-slate-intelligence/`.

- `DailySlateOrchestratorService` loads the Daily Slate once.
- Home Run Intelligence and Moneyline Intelligence expose `fromSlate` entry points so the orchestrator can reuse the same slate data.
- Existing prop recommendations from the Daily Slate supply Strikeout and Hits sections.
- Existing Home Run and Moneyline services supply their market-specific outputs.
- `RankingEngineService` ranks normalized candidates across every market.
- React consumes only `DailySlateIntelligenceViewModel`.

React does not import providers, call APIs, or calculate rankings.

## Services Used

Daily Slate Intelligence reuses:

- Daily Slate service
- RankingEngineService
- Home Run Intelligence service
- Moneyline Intelligence service
- Existing prop data for Strikeouts and Hits
- Weather profiles already attached to the slate
- Bullpen profiles already attached to team strength
- Lineup profiles already attached to teams

The existing Home Run and Moneyline services continue to use their downstream normalized services, including PlayerIntelligenceService, MatchupService, WeatherService, BallparkService, BullpenService, and LineupService.

## Data Flow

1. Load `DailySlateViewModel`.
2. Pass that slate into Home Run Intelligence and Moneyline Intelligence.
3. Convert strikeout props, hit props, home run candidates, and moneyline evaluations into normalized `BetCandidate` records.
4. Rank all candidates with `RankingEngineService`.
5. Split ranked output into market sections.
6. Generate weather, bullpen, and lineup alerts from normalized slate context.
7. Return one `DailySlateIntelligenceViewModel` to the homepage.

## View Model

The view model includes:

- Top Bets
- Strikeouts
- Hits
- Home Runs
- Moneyline
- Weather alerts
- Bullpen alerts
- Lineup alerts
- Market summary
- Slate metadata

Each recommendation includes a research link to the relevant lab.

## Current Limitations

- Strikeout and Hits sections currently use existing prop outputs rather than full market-specific lab rankings.
- Home Run and Moneyline candidates are ranked from their current V1 service outputs.
- Alerts are deterministic summaries of normalized data and do not yet include historical alert performance.
- No new predictions are generated by this layer.

## Future Expansion

Daily Slate V3 should add:

- Native Strikeout Lab candidate feeds.
- Native Hits and Total Bases candidate feeds.
- Closing line value tracking.
- User-specific saved filters.
- Market movement summaries.
- Confidence changes throughout the day.
- Direct links into player, matchup, and ballpark research pages with selected entities.
- Historical slate performance by market and model version.
